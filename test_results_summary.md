## Trade‑off Aggregation & Plot

The script `scripts/analyze_tradeoff.py` produced the following artifacts, which are useful for the paper:

- CSV summary: `tradeoff.csv` (raw) and `tradeoff_clean.csv` (cleaned)
- Plots: `tradeoff.png` and `tradeoff_clean.png`

Both the CSV and PNG files reside in the `results/` directory and can be referenced directly in the manuscript.
